# Atelier Céramique Lyon

Site vitrine 3 pages pour un atelier de céramique artisanale lyonnais.

## Pages

**index.html** : Accueil avec hero, section à propos, valeurs, sélection d'œuvres et CTA
**galerie.html** : Galerie d'œuvres en grille responsive
**contact.html** : Formulaire de contact et infos pratiques

## Choix techniques

**Bootstrap 5.3.3**
via CDN pour la grille et les composants

**CSS Custom**
pour ma charte graphique

**Bootsrap Icons**
pour les icones
